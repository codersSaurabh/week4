# Major Projects Collection Archive

This ZIP file contains three completely separate, independent, and full-featured React applications built with standard JavaScript / JSX and Tailwind CSS.

## 📂 Included Folders:

1. **`1-ecommerce-app/`**
   - Product listing & search
   - Interactive shopping cart & checkout modal
   - Admin CRUD dashboard for inventory control

2. **`2-social-media-feed/`**
   - Multi-user registration & post creation
   - Likes & nested comments
   - Simulated WebSocket real-time incoming post feed

3. **`3-project-management-dashboard/`**
   - Dynamic Kanban board with Drag-and-Drop columns & cards
   - Task detail drawers, subtasks, checklists, and priorities
   - Role-Based Access Control (Admin, PM, Member, Viewer)
   - LocalStorage data persistence

---

## 🚀 How to Run Any Project

Open your terminal and execute the following commands for the project you wish to run:

```bash
# 1. Navigate into the specific project directory:
cd 1-ecommerce-app
# (or cd 2-social-media-feed / cd 3-project-management-dashboard)

# 2. Install dependencies:
npm install

# 3. Start the application:
npm start
```
